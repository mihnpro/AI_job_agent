# 🤖 AI Job Agent

Автономный AI агент для поиска и автоматического отклика на вакансии на HH.ru с использованием языковых моделей.

## 🎯 Возможности

1. **Интеллектуальный поиск** - AI анализирует запрос пользователя и формирует оптимальную стратегию поиска
2. **Автоматический анализ** - Детальный AI-анализ вакансий по 6 критериям
3. **Умные автоотклики** - Автоматическое составление сопроводительных писем и отправка откликов
4. **Контекстная работа** - Агент учитывает ваше резюме при анализе вакансий
5. **Сохранение сессий** - Использование persistent профиля браузера для сохранения логина

## 🚀 Принцип работы

### 1. Планирование (AI Planning)

Пользователь → AI Анализ задачи → Пошаговый план действий

AI агент принимает задачу пользователя, анализирует её и создает оптимальный план:

```json
[
  {
    "action": "navigate",
    "reason": "Перейти на главную страницу HH.ru"
  },
  {
    "action": "search",
    "reason": "Выполнить поиск по запросу пользователя"
  },
  {
    "action": "extract_jobs",
    "reason": "Извлечь вакансии со страницы"
  },
  {
    "action": "evaluate_jobs",
    "reason": "Проанализировать вакансии с помощью AI"
  },
  {
    "action": "apply_to_relevant",
    "reason": "Откликнуться на подходящие вакансии"
  }
]
```

### 2. Извлечение данных (Data Extraction)

Агент использует Playwright для взаимодействия с [HH.ru](https://hh.ru/):

- Находит элементы вакансий по CSS-селекторам
- Извлекает заголовок, компанию, описание и ссылку
- Фильтрует рекламные и нерелевантные ссылки

### 3. AI-анализ (Intelligent Analysis)

Каждая вакансия анализируется по 6 критериям:

- Соответствие должности запросу пользователя
- Совпадение навыков с резюме кандидата
- Уровень опыта (junior/middle/senior)
- Зарплатные ожидания (если указаны)
- Локация и формат работы (офис/удаленка)
- Плюсы и минусы вакансии

Анализ возвращается в формате:

```json
{
  "is_relevant": true,
  "reason": "Краткое обоснование",
  "match_score": 8,
  "recommendation": "apply",
  "analysis": "Детальный анализ на 3-4 предложения",
  "skills_match": ["Python", "Django", "SQL"],
  "requirements": ["Опыт работы 2+ года", "Знание Python"]
}
```
### 4. Автоотклики (Auto-application)

Для подходящих вакансий (оценка ≥7/10):

- Открывается страница вакансии в новой вкладке
- AI генерирует персонализированное сопроводительное письмо
- Заполняются поля формы
- Отправляется отклик

### 5. Анти-детекция (Anti-detection)

Для избежания блокировок:

- Случайные User-Agent
- Stealth-скрипты для скрытия автоматизации
- Human-like задержки между действиями
- Блокировка рекламных трекеров

## 🛠️ Технологический стек

- **Playwright** - Автоматизация браузера
- **Ollama** - Локальные языковые модели
- **Qwen2.5:7b** - AI модель для анализа
- **Go** - Бэкенд агента
## 📦 Установка

### 1. Установите зависимости

```bash
# Установите Playwright
npm init playwright@latest
# или
go install github.com/playwright-community/playwright-go/cmd/playwright-go@latest

# Установите браузеры
playwright install chromium

# Установите Ollama
# macOS/Linux
curl -fsSL https://ollama.ai/install.sh | sh

# Windows
winget install Ollama.Ollama
```

### 2. Установите AI модель
```
bash
# Установите модель (рекомендуется Qwen2.5)
ollama pull qwen2.5:7b
# или для меньшего потребления памяти
ollama pull qwen2.5:3b
### 3. Соберите проект
bash
# Клонируйте репозиторий
git clone <repository-url>
cd Ai_agent_2
```
# Соберите бинарник
```
bash
go build -o ai-job-agent main.go
```

## 🎮 Использование
### Базовые команды
```
bash
# Поиск вакансий с AI анализом
./ai-job-agent --task="найди 5 вакансий Python разработчика в Москве"

# С автооткликами (headless режим)
./ai-job-agent --task="найди работу AI инженером" --auto-apply=true --headless=true

# С видимым браузером для отладки
./ai-job-agent --task="найди backend вакансии" --debug=true --headless=false

# Интерактивный режим
./ai-job-agent --interactive
```
## Параметры командной строки
### Параметр	Описание	По умолчанию

| Параметр      | Описание                              | По умолчанию              |
|---------------|---------------------------------------|---------------------------|
| `--task`      | Задача для агента                     | Запрашивается             |
| `--headless`  | Запуск браузера в фоновом режиме      | `true`                    |
| `--auto-apply`| Включить автоотклики                  | `false`                   |
| `--debug`     | Режим отладки                         | `false`                   |
| `--profile`   | Директория профиля браузера           | `~/.ai-job-agent/profile` |
